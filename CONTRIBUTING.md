# Contributing

Contributions should improve the clarity, accessibility, reproducibility, or safety of the reference workflow.

- Do not submit real participant records, credentials, consent forms containing personal contact details, or institution-specific materials without permission.
- Use synthetic fixtures for tests and examples.
- Keep privacy-sensitive defaults explicit and avoid collecting fields that the example does not need.
- Run `npm run build` and `python3 -m unittest discover -s analysis/tests -v` before opening a pull request.
