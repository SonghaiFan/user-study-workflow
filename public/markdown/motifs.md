# Sample response patterns

The demo offers a small set of visual patterns. Replace these descriptions and diagrams with study materials that you have permission to distribute.

| Pattern | Sample interpretation |
| --- | --- |
| Linear | One topic continues across several updates. |
| Arch | A topic changes and later returns. |
| Ladder | A new topic appears at each step. |
| LateTurn | The topic changes near the end. |
| EarlyTurn | The topic changes near the beginning. |
| WideBranch | One topic separates into two. |
| WideMerge | Two topics converge into one. |
| SharpMerge | A later update returns to an earlier topic. |
| SharpBranch | One of two topics continues after a split. |
